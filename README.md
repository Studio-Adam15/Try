# Istatieh Decor — استيتيه للديكور والستائر

Luxury interior decoration showroom website for Istatieh Decor, specializing in premium wallpapers, bespoke curtains, and architectural finishes.

## Tech Stack
- React 19 + TypeScript
- Vite
- Tailwind CSS
- Bun
- Motion (Framer Motion)
- Lucide React

## Development
```bash
bun install
bun run dev
```

## Build
```bash
bun run build
```
